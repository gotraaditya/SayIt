# SayIt Case Study Carousel

This folder contains the editable source and export-ready assets for a 10-slide SayIt product case study.

## Format

- Canvas: 1080 x 1350 px (4:5 portrait)
- Instagram: upload the numbered PNG files from `exports/` in order
- LinkedIn: upload `output/pdf/sayit-case-study-ui-palette-v2.pdf` as a document post
- Editable source: `carousel.html` and `carousel.css`
- Social captions and alt text: `POST_COPY.md`
- Overview preview: `exports/sayit-case-study-contact-sheet.png`

The design uses the product's local Instrument Sans and DM Mono font files, the SayIt mark from `docs/assets/brand/logo.svg`, the interface's carbon, bone, stone, and burnt-orange palette, and a real browser capture of the compact widget.

## Narrative

1. Product promise
2. Problem and opportunity
3. Experience principles
4. Core interaction
5. Micro-widget design
6. Caption-led playback
7. Local-first architecture
8. Resilience and validation
9. Outcome and trade-offs
10. Reflection

Open `carousel.html` in a browser to review all slides. Add `?slide=01` through `?slide=10` to isolate a slide for export.
